## Why I'm doing this again

I've "done" DSA before in the sense of seeing solutions. This time I want to actually be able to reason through problems myself: state, invariants, complexity, dry runs.

## How I set it up

- **A resource map** so I'm not hopping between ten courses. Runestone Academy for first exposure, MIT 6.006 for depth, NeetCode for pattern practice, each with a specific job.
- **Mentor rules** for when I use AI to study: hints before solutions, I explain my reasoning first, complexity is always required, and I periodically test myself without notes or AI.
- **A progress file and a session journal** to track weak areas and recurring mistakes.
